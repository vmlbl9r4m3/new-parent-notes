# 【健康科普】产后”躺瘦”难道不香吗？

> 更新时间：2026-09-16 (UTC+8)

点击上方蓝字 关注我们减肥是女人穷尽一生的事业，但产后却是很多女人减肥史上难以逾越的鸿沟。小肚腩、扁塌臀、松垮腰，以前的衣服完全容不下现在膨胀的躯体了！

“为什么人家产前产后依旧，我却长了一身肥肉？”“有没有什么简单的产后瘦身的办法呢？”当然有，我来告诉大家三个产后躺瘦的办法。1.
**宝妈专属，那就是母乳喂养**

因为母乳喂养会让你每天多消耗300-500卡路里。几乎等于走路2小时，跑步1小时！躺着喂养是一种非常友好且科学的方式，宝妈和宝宝侧卧，胸贴胸，腹贴腹，脸对着乳房，让宝宝张大嘴，把乳头和大部分乳晕含进去。躺喂最大的好处莫过于妈妈可以放开手臂，舒服的躺着!夜间哺乳尤其明显，不需要从温暖的被窝一遍一遍的爬起来，可以和宝宝一同休息，躺喂的最高境界就是——自助奶。
2.
**腹式呼吸**
无论顺产还是剖宫产，产后腹部都松垮和无力，产妇对于那些复杂和有力量的运动心有余而力不足。而呼吸存在于每时每刻，一个人一天会进行2万多次呼吸运动。

女性在将胸式呼吸调整为腹式呼吸，在一定程度上可以减脂塑形，让腹部更紧实，同时减少产后焦虑感，也是产后康复的基础。

呼吸要深长而缓慢。用鼻吸气用口呼气。一呼一吸掌握在15秒钟左右。即深吸气(鼓起肚子)3—5秒，屏息1秒，然后慢呼气(回缩肚子)3—5秒，屏息1秒。每次5—15分钟。做30分钟最好。

身体好的人，屏息时间可延长，呼吸节奏尽量放慢加深。身体差的人，可以不屏息，但气要吸足。每天练习1—2组，每组腹部尽量做到鼓起缩回50-100次，练到微热微汗即可。

3.**躺瘦升级，这三个招式一定要学会**

**臀桥**

适合顺产后7天开始，剖宫产后21天开始。

放松吸气、吐气，臀部抬起，保持肩髋膝同水平面，腹部臀部盆底肌收紧，每天5-10组。

臀桥不仅对于胯部和腹肌都有很好的塑型效果，还可以提拉臀部线条，让臀型更美更翘。

**拱背运动**

适合顺产后7天开始、剖宫产后21天开始。

开始时保持背部平直，然后慢慢向下向前再向上慢慢拱起，像一只猫在伸懒腰一样。每次5-10次为一组，每次锻炼2组以上。拱背运动可以锻炼背肌，燃烧背部脂肪。

**脚踩运动**

适合顺产第一天开始。

平躺于床上，抬起双腿，膝盖自然弯曲，两腿像踩自行车踏板一样，来回循环，如果有力量，可以尽量绷直反复练习。能改善血液循环，防止脚部肿胀，每次20-30次为一组，每次锻炼3组以上，循序渐进地训练。
