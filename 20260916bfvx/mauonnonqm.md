# 最新！福建医科大学附属第一医院关于门诊及住院工作的通知

> 更新时间：2026-09-16 (UTC+8)

关于门诊工作的通知

尊敬的患者及家属：

一、经医院研究，决定自2月26日起恢复**口腔科**、**耳鼻咽喉科、眼科**门诊。

二、目前，仍处于疫情防控攻坚阶段，特将就诊注意事项通知如下，请您配合：

1.

门诊楼、外科楼及内科楼各入口设置体温监测点，请自觉接受体温监测；

2.

**佩戴口罩**：所有人员进入院区须全程正确佩戴口罩；

3.

严格执行“一人一诊一室”，避免患者二次聚集；如有需要，**限1名陪同人员进入诊室**；

4.

实行**分时段全预约**：建议患者来院前提早预约，分时段就诊，避开高峰，以减少在医院内等候逗留时间，避免交叉感染；

5.

鼓励病友充分利用**福建医科大学附属第一医院互联网医院开展慢病**咨询等。

6.

**凡有以下情况之一者，请主动告知并前往发热门诊接受筛查：**
1.发热（体温≥37.4℃）；2.近两周内去过武汉及周边地区，或其他有本地病例持续传播地区的旅行史或居住史；3.近两周明确接触来自武汉及周边地区，或其他有本地病例持续传播地区的发热或有呼吸道症状患者；4.身边有多名人员发热。

关于住院工作的通知

1.

住院病友因病情需要可安排1名固定陪护人员（护理员），并严格遵守陪护人员相关规定；

2.

陪护人员（护理员）由医院护工服务站统一调配，不得私自外请；

3.

住院患友及陪护人员（护理员）原则上不得外出；

4.

住院患友和护理员应积极配合做好体温监测和相关情况问询；

5.

鼓励住院患友和护理员由医院膳食部（食堂一层）订餐、送餐；

6.

疫情防控期间，病区谢绝探视；

7.

**出院患友的复查、随诊等统一在门诊进行。**

以上措施可能对就医，带来一定的不便，但是实属必要。为了在抗疫期间全力保护广大患友、患友家人以及医务人员的安全和健康，敬请大家配合！感谢您的支持！
